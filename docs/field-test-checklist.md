# Checklist ທົດສອບໃນຫ້ອງຄອມ (ກ່ອນໃຊ້ທັງຫ້ອງ)

ທົດສອບໃນເຄື່ອງ 1–2 ເຄື່ອງກ່ອນ: **ເຄື່ອງ A** = RAM 4GB + HDD, **ເຄື່ອງ B** = SSD (ຖ້າມີ).
ເປີດ `ClassroomChecker.exe` ຈາກ USB ແບບ Admin ຂະນະທີ່ **ບັນຊີນັກຮຽນ login ຢູ່**.

ເຄື່ອງ: ______________  Windows: ☐ 10 Pro ☐ 11 Pro   ຜູ້ທົດສອບ: ______________  ວັນທີ: ____/____/______

---

## 0. ກຽມ USB
- ☐ ໂຟນເດີ `installers/` ມີໄຟລ໌ Setup ທີ່ຊື່ມີ `sumatra`, `laoscript` (ຫຼື `ls8`), `vlc`, `7z`
- ☐ ຕັ້ງຄ່າ → ທົ່ວໄປ: ຄຳນຳໜ້າຊື່ user = `LTVC` → ຕົວຢ່າງສະແດງ `LTVC-COM1-01` → ກົດ **ບັນທຶກ**
- ☐ ປຸ່ມ **ບັນທຶກ / ຍົກເລີກ** ສະແດງໃນທຸກແທັບຂອງໜ້າຕັ້ງຄ່າ

## 1. ໜ້າຕາໂປຣແກຣມ (UI)
- ☐ Header: ປຸ່ມ ຕັ້ງຄ່າດ່ວນ / ຕັ້ງຄ່າ / ຄູ່ມື ບໍ່ແຕກແຖວ, ຂໍ້ຄວາມບໍ່ທັບກັນ
- ☐ ແທັບ ຕິດຕັ້ງຊອບແວ: ລາຍການບໍ່ຂຶ້ນຊ້ຳ, ບໍ່ມີ scrollbar ແນວນອນ
- ☐ ແທັບ Antivirus USB: ກ່ອງເລືອກ Drive ແລະ ປຸ່ມ ກວດຫາ/ເລືອກ ເຫັນຄົບ
- ☐ ປ່ຽນເປັນ English: ປຸ່ມ ແລະ ແທັບ ບໍ່ຖືກຕັດ

## 2. ຊອບແວພື້ນຖານ (ແທັບ ກວດສອບລະບົບ)
- ☐ ສະແກນ: ຫົວຂໍ້ "ຊອບແວພື້ນຖານ (PDF, LaoScript 8, VLC, 7-Zip)" ບອກໂຕທີ່ຂາດຖືກຕ້ອງ
- ☐ ກົດ ແກ້ໄຂ: ຕິດຕັ້ງສະເພາະໂຕທີ່ຂາດ, ບໍ່ຕິດຕັ້ງໂປຣແກຣມອື່ນ
- ☐ ສະແກນຊ້ຳ: ✓ ຜ່ານ

## 3. ວັນທີ & ເວລາ
- ☐ ຕັ້ງຄ່າ → ວັນທີ & ເວລາ: ໂມງຕົວຢ່າງເດີນ, ເລືອກ 12 ຊົ່ວໂມງ ແລ້ວຕົວຢ່າງປ່ຽນເປັນ `2:30:00 PM`
- ☐ ບັນທຶກ → ສະແກນ → ແກ້ໄຂ "ວັນທີ & ເວລາ": ໂມງ Taskbar ປ່ຽນເປັນ 12 ຊົ່ວໂມງ
- ☐ ກັບເປັນ 24 ຊົ່ວໂມງ ແລ້ວແກ້ໄຂອີກຄັ້ງ: ໂມງກັບຄືນ
- ☐ ໂມງ Taskbar ຂອງ **ບັນຊີນັກຮຽນ** ປ່ຽນ (ບໍ່ແມ່ນສະເພາະບັນຊີ Admin)

## 4. ໄອຄອນໜ້າຈໍ
- ☐ This PC ແລະ Control Panel ສະແດງເປັນໄອຄອນລະບົບ (ບໍ່ມີລູກສອນ shortcut)
- ☐ ເຄື່ອງທີ່ມີ Word/Excel/PowerPoint ຢູ່ Desktop ແລ້ວ: ກົດ ແກ້ໄຂ 2 ຄັ້ງ → **ບໍ່ມີໄອຄອນຊ້ຳ**
- ☐ ເຄື່ອງທີ່ບໍ່ມີ: ສ້າງ 3 ໄອຄອນ ພຽງເທື່ອດຽວ

## 5. ພື້ນຫຼັງ, ໜ້າ Lock & Login
- ☐ ກົດ ກຳນົດພື້ນຫຼັງ: ກ່ອງຂໍ້ຄວາມສະແດງ ✓ ຂອງ Lock / blur / ລັອກພື້ນຫຼັງ
- ☐ ກົດ Win+L: ໜ້າ Lock ເປັນຮູບຫ້ອງ + ເລກເຄື່ອງ
- ☐ Sign out: ໜ້າ Welcome ເປັນຮູບດຽວກັນ ແລະ **ບໍ່ມົວ**
- ☐ Login ນັກຮຽນ → ຄລິກຂວາຮູບ → Set as desktop background: **ປ່ຽນບໍ່ໄດ້**
- ☐ ເປີດ ຂໍ້ຄວາມກ່ອນ Login → ກຳນົດພື້ນຫຼັງ → Restart: ກ່ອງກົດລະບຽບສະແດງ, **ພາສາລາວອ່ານໄດ້**, ຂຶ້ນແຖວຖືກ
- ☐ ປິດທຸກຕົວເລືອກ → ກຳນົດພື້ນຫຼັງ ອີກຄັ້ງ → Restart: ທຸກຢ່າງກັບເປັນຄືເກົ່າ

## 6. ປ່ຽນຊື່ຄອມ ແລະ ຊື່ user
- ☐ ກົດ ປ່ຽນຊື່ເຄື່ອງ: ກ່ອງຢືນຢັນບອກ ຊື່ເຄື່ອງ → `COM1-01` ແລະ ຊື່ user → `LTVC-COM1-01`
- ☐ Restart → Login ດ້ວຍ `LTVC-COM1-01` (ລະຫັດເດີມ)
- ☐ Desktop, Documents, ໄຟລ໌ຂອງນັກຮຽນ ຍັງຢູ່ຄົບ
- ☐ ເຄື່ອງທີ່ເປີດ Auto-login: ຍັງ login ເອງໄດ້
- ☐ ເປີດໂຟນເດີແຊຣ໌ / Printer ໃນ network ໄດ້ປົກກະຕິ (ຖ້າຫ້ອງໃຊ້)

## 7. ໂໝດເຄື່ອງສະເປັກຕ່ຳ (ເຄື່ອງ A: 4GB + HDD)
ກ່ອນປັບ ຈົດເວລາ: Boot ຮອດ Desktop ______ ວິ, ເປີດ Word ______ ວິ, RAM ທີ່ໃຊ້ (Task Manager) ______ GB

- ☐ ສະແກນ: ຫົວຂໍ້ "ໂໝດເຄື່ອງສະເປັກຕ່ຳ" ບອກ RAM, **HDD** ແລະ ແນະນຳ SSD
- ☐ ກົດ ແກ້ໄຂ → Restart

ຫຼັງປັບ: Boot ______ ວິ, ເປີດ Word ______ ວິ, RAM ທີ່ໃຊ້ ______ GB

- ☐ ຕົວໜັງສືລາວ ແລະ ໜ້າຕ່າງສະແດງປົກກະຕິ
- ☐ ພິມຊື່ໂປຣແກຣມໃນ Start (ເຊັ່ນ Word) ຄົ້ນຫາພົບ
- ☐ ສຽງ, Printer, Wi-Fi/LAN, USB ໃຊ້ໄດ້
- ☐ Windows Update ແລະ Defender ຍັງເຮັດວຽກ
- ☐ ເຄື່ອງ B (SSD ຫຼື RAM 8GB+): ສະແກນ → "ບໍ່ຕ້ອງປັບ"
- ☐ ຕັ້ງຄ່າ → ລ້າງໄຟລ໌ຂີ້ເຫຍື້ອ → **ຄືນຄ່າເດີມຂອງເຄື່ອງນີ້** → Restart: ທຸກຢ່າງກັບຄືນ

## 8. Quick Setup (ເຄື່ອງໃໝ່)
- ☐ ສະແດງ 11 ຂັ້ນຕອນ (ຂໍ້ 10 = ໂໝດເຄື່ອງສະເປັກຕ່ຳ, ຂໍ້ 11 = ປ່ຽນຊື່ເຄື່ອງ)
- ☐ ແລ່ນຄົບທຸກຂັ້ນຕອນ ✓, ເລກເຄື່ອງຕໍ່ໄປເພີ່ມຂຶ້ນ 1
