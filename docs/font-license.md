# ກວດ license ຂອງ font Phetsarath OT ກ່ອນແຈກຢາຍ (ຂໍ້ 14)

ອ້າງອີງ: cm-spec ຂໍ້ 5.2 ແລະ ຂໍ້ 10 — ຜູ້ໃຊ້ຕ້ອງຢືນຢັນວ່າແຈກຢາຍໄດ້ ກ່ອນຝັງ font ໃນ exe.

> [!IMPORTANT]
> ເອກະສານນີ້ເປັນ checklist ເທົ່ານັ້ນ. **ຂ້ອຍບໍ່ໄດ້ຢືນຢັນ license ຂອງ font ນີ້** ແລະ ບໍ່ສາມາດຢືນຢັນແທນເຈົ້າຂອງ font ໄດ້.
> ການຕັດສິນວ່າແຈກຢາຍໄດ້ຫຼືບໍ່ ຕ້ອງອີງໃສ່ເອກະສານ license ຈາກຜູ້ເຜີຍແຜ່ font.

## ສະຖານະປັດຈຸບັນ

- ໄຟລ໌ `src/ClassroomChecker/Assets/Fonts/PhetsarathOT.ttf` (188,704 bytes) ຖືກຝັງເປັນ EmbeddedResource ໃນ exe.
- ແອັບໃຊ້ມັນ 3 ຢ່າງ: (1) ແຕ້ມຂໍ້ຄວາມໃນ wallpaper, (2) ເປັນ font ຂອງ UI, (3) **ຕິດຕັ້ງລົງ `C:\Windows\Fonts`** ໃນເຄື່ອງຫ້ອງຮຽນ (FontCheckModule.Fix).
- ຂໍ້ (3) ແມ່ນການແຈກຢາຍ font ອອກໄປຍັງຫຼາຍເຄື່ອງ ສະນັ້ນ license ຕ້ອງອະນຸຍາດ redistribution + ການຕິດຕັ້ງ.

## ຕ້ອງກວດຫຍັງແດ່

1. **ແຫຼ່ງທີ່ມາ**: ໄດ້ font ນີ້ຈາກໃສ? (ເວັບຜູ້ເຜີຍແຜ່, ກະຊວງ/ໜ່ວຍງານ, ຊຸດຕິດຕັ້ງ Office, ຫຼືອື່ນໆ). ເກັບ URL/ເອກະສານໄວ້.
2. **ໃບອະນຸຍາດ**: ຫາໄຟລ໌ license ທີ່ມາກັບ font ຕົ້ນສະບັບ (EULA, OFL, ຫຼື README). ອ່ານວ່າອະນຸຍາດ:
   - ການຝັງໃນໂປຣແກຣມ (embedding) ບໍ?
   - ການແຈກຢາຍສຳເນົາ (redistribution) ບໍ?
   - ການຕິດຕັ້ງໃນຫຼາຍເຄື່ອງ ແລະ ໃນໂຮງຮຽນ/ອົງກອນ ບໍ?
   - ການນຳໄປຂຽນລົງຮູບ (wallpaper) ບໍ?
3. **ເງື່ອນໄຂເພີ່ມເຕີມ**: ຕ້ອງໃສ່ຊື່ຜູ້ຖືລິຂະສິດ, ແຈກຢາຍພ້ອມ license, ຫ້າມຂາຍ, ຫ້າມປ່ຽນຊື່ — ຖ້າມີ ຕ້ອງເຮັດຕາມ.
4. **ກວດ metadata ໃນໄຟລ໌ font**: ໃນ Windows ກົດຂວາ `PhetsarathOT.ttf` → Properties → Details ເບິ່ງ *Copyright*,
   *License description*, *License information URL*. ຖ້າຫວ່າງ ບໍ່ໄດ້ແປວ່າແຈກຢາຍໄດ້ — ຕ້ອງອ້າງອີງເອກະສານທາງການ.
5. **ບັນທຶກຜົນ**: ຂຽນລົງຕາຕະລາງລຸ່ມນີ້ ແລ້ວອັບເດດ cm-spec ຂໍ້ 10 ວ່າ "ຢືນຢັນແລ້ວ".

## ຖ້າ license ບໍ່ອະນຸຍາດ ຫຼື ບໍ່ແນ່ໃຈ

ແອັບຮອງຮັບທາງເລືອກທີ່ບໍ່ຕ້ອງຝັງ font:
- ເອົາ `PhetsarathOT.ttf` ອອກຈາກ `Assets/Fonts/` ແລະ `.csproj`, ແລ້ວໃຫ້ແອັບໃຊ້ **Leelawadee UI** (ມີໃນ Windows ແລະ ຮອງຮັບລາວ — cm-spec ຂໍ້ 6) ເປັນ font ຂອງ UI/wallpaper.
- ຫຼື ວາງ font ທີ່ມີ license ຖືກຕ້ອງໄວ້ໃນໂຟນເດີ `fonts/` ຂ້າງ exe (spec ຂໍ້ 5.2 ຮອງຮັບ) ແທນການຝັງ.
- ການປ່ຽນນີ້ກະທົບ `FontCheckModule`, `UiFontManager` ແລະ `WallpaperModule` ສະນັ້ນຕ້ອງທົດສອບໃໝ່.
